# Electromagnetic Radiation

An interactive module on electromagnetic radiation for chemistry students.

**Live site:** https://sunitathyagarajan.github.io/em-radiation/

## What's in it

- **The electromagnetic spectrum:** wavelength, frequency, wavenumber and photon energy, a worked example, a spectrum explorer that converts between any of them, and a table of every region's wavelength, frequency and energy ranges
- **Seven types of radiation, longest wavelength to shortest:** radio, microwave, infrared, visible, ultraviolet, X-ray and gamma. For each: what it is, what it reveals about chemical structure or atoms, how it is made, and the balanced chemical or nuclear equations that go with it
- **Interactive and animated diagrams:** an antenna and the NMR energy gap, a magnetron and the CO rotational ladder, CO₂ vibrations and blackbody sources, the hydrogen emission spectrum, conjugation and a deuterium lamp, the steps that make a Kα X-ray and an X-ray tube spectrum, Bragg diffraction, a cobalt-60 decay scheme and gamma-ray detector spectra
- A summary table of which radiation answers which question

## Files

- `index.html`: the module itself, one self-contained page
- `references.html`: sources for the region boundaries, constants and the atomic, X-ray and nuclear data

To change the site, edit these files and push to `main`; GitHub Pages republishes automatically.
